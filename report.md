# Mini Project 2 - Part 2: Chatbot Report

## Overview

A conversational chatbot built with **Streamlit** and **OpenAI GPT-3.5-turbo**. The chatbot maintains conversation history using `st.session_state`, allowing it to remember context across multiple turns.
